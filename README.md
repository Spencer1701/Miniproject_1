# Miniproject_1
First Miniproject for Senior Design

A USB-powered MicroPython meeting timer using a XIAO ESP32-S3, a stepper-driven
clock hand, two buttons, and an RGB LED. Presets are 15, 20, 25, and 30 minutes.
An enclosure is optional for this team, which has no mechanical engineering members.

Use [code/meeting_timer.py](code/meeting_timer.py). See the
[operating instructions](docs/operating-instructions.md),
[state chart](docs/state-chart.md), and [references](docs/references.md).
Current verification and remaining submission items are in [firmware notes](docs/firmware.md).
