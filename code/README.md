# Code

[meeting_timer.py](meeting_timer.py) is the final standalone MicroPython program.
Open it in Thonny and press F5, or save it on the device as `main.py` for startup.
It uses real 15/20/25/30-minute presets, motor direction `-1`, and RGB GPIOs
`(8, 9, 7)`. See the [operating instructions](../docs/operating-instructions.md).
