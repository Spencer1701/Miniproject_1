# 3D printing files

**Printed design:** [mini_clock_face_and_hands.stl](mini_clock_face_and_hands.stl).
The combined file contains the compact 82 × 82 × 2 mm clock face with an LED
opening and three alternative shaft-fit hands. The full layout is
135.2 × 82 × 6 mm. Install one hand. Reprint at 100% scale in millimetres,
flat as supplied, using a slicer profile for the actual printer.

[timer_lid_flat_v2.stl](timer_lid_flat_v2.stl) and
[timer_base_and_parts_v2.stl](timer_base_and_parts_v2.stl) are earlier optional
full-enclosure prototypes retained to show the design iterations. Their
physical fit has not been verified.
