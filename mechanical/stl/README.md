# STL files

**Selected print job:** [mini_clock_face_and_hands.stl](mini_clock_face_and_hands.stl).
This is the original combined file supplied for the team's compact print,
containing an 82 × 82 × 2 mm face and three alternative shaft-fit hands.
The complete layout is 135.2 × 82 × 6 mm, in millimetres. The dial increases
clockwise from 0/30 and includes a 5.4 mm LED opening. Install one hand.

For a reprint, import this file at 100% scale, flat as supplied, with lettering
and hand hubs facing up. Slice for the actual printer; the STL does not contain
printer settings. TODO: record the printer, material, slicer settings, actual
